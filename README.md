## Description

[Описание дипломного проекта](https://github.com/netology-code/ndjs-diplom)

## Installation

```bash
$ npm install
```

## Running the app by docker-compose

```bash
docker-compose up
```

## Running the app locally

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
